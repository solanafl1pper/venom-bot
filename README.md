# sud-bot

Discord-бот, который по команде выдаёт участнику случайную «судимость» по статьям УК РФ и ведёт рекорд.

## Команды

| Команда | Что делает |
|---|---|
| `/судимость` | Судимость автора команды, с пингом |
| `/судимость @участник` | Судимость другого участника, с пингом |
| `/рейтинг` | Топ-10 по рейтингу |
| `/войс` | Сколько часов провёл в войсе (своё или другого) |
| `/войстоп` | Доска почёта: кто дольше всех сидит в голосовых каналах |
| `/2048` | Играть в 2048 кнопками прямо в чате |
| `/погода` | Погода в городе по умолчанию |
| `/погода Казань` | Погода в любом городе |
| `/рандом` | Случайный состав на Доту 2 |
| `/помощь` | Справка (приватная) |

## Судимость — свежий розыгрыш каждый раз

Каждый вызов `/судимость` — это новый розыгрыш, а не накопление:

- выпадает случайное число статей от **1 до 15**;
- прошлый набор **полностью заменяется** новым;
- повторов внутри одного дела нет;
- в карточке видно «📚 Судимостей: N из 15» и «🏆 Рекорд»;
- если выпало больше статей, чем когда-либо раньше, — это **новый рекорд**, бот подсвечивает его баннером;
- старое сообщение бота с прошлой судимостью **удаляется** при новой попытке;
- между попытками — **кулдаун 15 минут**. Если звать команду раньше, бот покажет, что ты в кулдауне, и сколько осталось ждать.

## Рейтинг

Рейтинг считает две вещи: **жёсткость срока** и **количество судимостей**.

```
рейтинг = сумма очков статей + 5 × число статей
```

Сумма очков — это жёсткость (небольшая 1, средняя 2, тяжкая 4, особо тяжкая 8), из неё же считается «срок». Плюс 5 очков за каждую статью — чтобы много судимостей было выгодно даже при лёгких составах.

**В зачёт идёт лучший результат за последние трое суток.** После каждой попытки запоминается замер (рейтинг, очки, число статей). В топе учитывается максимум среди замеров, которым не больше 72 часов; всё, что старше, выпадает из окна. Если свежих замеров вообще нет, берётся текущий результат, чтобы участник не исчезал из топа совсем.

## 2048

`/2048` создаёт поле 4×4 и кнопки со стрелками. Ходы считаются только те, что реально сдвинули поле, при бессмысленном ходе бот тихо объясняет, что поле не сдвинется. Есть счёт, число ходов, максимальная плитка и рекорд, который сохраняется в `data/sud.json` и переживает перезапуск. Игра живёт 2 часа, потом кнопки гаснут.

## Погода

`/погода` — город по умолчанию из `WEATHER_CITY`. `/погода Казань` — любой город. Данные кэшируются на 10 минут отдельно для каждого города, источник — **Open-Meteo** (бесплатно, без API-ключа), 28 кодов погоды WMO переведены на русский с эмодзи. Если API недоступен, бот честно пишет об ошибке и продолжает работать. Проверить: `npm run weather` или `npm run weather -- Казань`.

## Рандом на Доту

`/рандом` собирает команду из **5 участников с ролью** (ID роли в `DOTA_ROLE_ID`, по умолчанию `1554512622634803223`) и раздаёт им по герою: керри, мид, оффлейн, софт- и хард-саппорт. Ботов пропускает, участников не повторяет, героя подбирает так, чтобы он подходил позиции.

Героев для каждой позиции берёт топ по пик-рейту из **Stratz API** (`STRATZ_TOKEN`), а если токена нет или API недоступен — честно откатывается на локальный список. Лейн и роль показывает прямо в карточке, тактик и предметов нет — только герои, лейны и пацаны.

Если участников с ролью меньше пяти, свободные слоты честно помечаются.

Роль задаётся в `.env`:
```
DOTA_ROLE_ID=1554512622634803223
```

## Подсчёт времени в войсе

Бот в реальном времени считает, сколько часов и минут каждый участник проводит в голосовых каналах:

- `/войс` — персональное войс-досье: общее время (в днях/часах/минутах и десятых долях часов), число посиделок, статус (сидит ли прямо сейчас, в каком канале и сколько времени), позиция в рейтинге и топ-5 болтунов сервера;
- `/войстоп` — общий топ сервера по времени в войсе с медалями и суммарным счётчиком компании;
- под сообщениями есть интерактивные кнопки `[🏆 Топ войса]` и `[👤 Моё время]` для быстрого просмотра прямо из чата;
- данные сохраняются каждые 30 секунд в `data/sud.json` — даже при перезапуске бота ни одна минута не потеряется;
- при старте бот автоматически подхватывает участников, которые уже сидят в голосовых каналах.

## Триггеры в чате

Бот реагирует на обычные сообщения без слеша — достаточно написать в любом канале:

- `РПП`
- `3 слова победы`
- `победа`
Регистр не важен, разделители внутри слова тоже:

| Триггер | Что ловит |
|---|---|
| `РПП` | `рпп`, `р.п.п`, `р п п`, `р_п_п`, `р-п-п`, `р/п/п`, `ррр`, `рррр`, `RPP`, `рПП` |
| `3 слова победы` | `3 слова победы`, `3. слова. победы`, `3-слова-победы`, `З слова победы`, `3слов победы` |
| `победа` | `победа`, `победу`, `победы`, `победой`, `победе`, `victory`, `ZOV`, `зов`, `з о в`, `З-О-В` |
| `аллах` | `аллах`, `аллаха`, `аллаху`, `аллахом`, `аллахе`, `Аллахи`, `акбар`, `Аллах Акбар`, `акабар` |

Латиница приводится к кириллице по визуальным аналогам, поэтому `ZOV` → `зов`, `RPP` → `рпп`, `зov` → `зов`. Слова вроде `победитель`, `победач`, `допобеда`, `алла`, `алмаз` не срабатывают.

Ответ — embed со случайной фразой из пула этого триггера. Автор пингуется. В embed встраиваются гифки по URL-ссылкам без вложенных файлов:

- `аллах` → `SHEEP_IMAGE_URL` (гифка с баранами)
- `победа` / `РПП` / `3 слова победы` → `VICTORY_IMAGE_URL` (гифка победы)

Ссылки задаются в `src/commands/trigger.js`.

- на `победа` / `РПП` / `3 слова победы`: заголовок **«РОССИЯ ПУТИН ПОБЕДА! ZOV ZOV ZOV»**, 16 фраз про ZOV
- на `аллах`: жёлтый заголовок **«🐏🐏🐏 СТАДО В СБОРЕ 🐏🐏🐏»**, 6 фраз про баранов

Защита от спама:
- cooldown 5 секунд на автора, повторный вброс подряд игнорируется;
- предыдущий ответ бота этому автору удаляется, чтобы не плодить сообщения;
- через 60 секунд ответ сам удаляется;
- сообщения от ботов игнорируются.

Cooldown меняется константой `COOLDOWN_MS` в `src/commands/trigger.js`.

Слова, фразы и заголовки меняются в `src/commands/trigger.js`: массив `TRIGGERS` (что ловить, цвет, заголовок, пул `messages`) и пулы `VICTORY_MESSAGES` / `SHEEP_MESSAGES`. Cooldown — константа `COOLDOWN_MS`.

## Статус бота

Бот держит в статусе две строки:

```
👥 33 человека · 2 сервера
жми /судимость
```

Сверху — сумма участников по всем серверам, где есть бот, с правильным склонением (`1 человек`, `3 человека`, `2048 человек`). Считается мгновенно при входе/выходе участника, иначе обновляется раз в 5 минут. Погоды в статусе нет — она живёт в команде `/погода`.

## Оформление

Мягкая палитра под «дружеского бота»: изумрудный, янтарь, оранжевый, розовый. Триггерные сообщения — без громких заголовков, просто текст с баранами или ZOV.

## Логика

- Каждый вызов `/судимость` — свежий розыгрыш: выпадает от 1 до 15 статей, прошлый набор заменяется.
- Рекорд — это максимальное число статей, выпавшее за всё время; новый рекорд подсвечивается в карточке.
- Между попытками — кулдаун 15 минут (`COOLDOWN_MS`). Внутри кулдауна бот сообщает, сколько осталось ждать.
- При новой попытке предыдущее сообщение бота с судимостью этого участника удаляется.
- Повторов внутри одного дела нет. Чем выше очки (small=1, medium=2, heavy=4, extreme=8), тем длиннее «срок».
- Очки статей суммируются → определяется категория преступления (ст. 15 УК РФ), цвет карточки и назначенный срок.

## Статьи

306 статей из УК РФ с частями, санкциями и категориями тяжести — `src/data/articles.js`.

Веса подобраны так, чтобы часто выпадали бытовые составы (ст. 116 побои, 158 кража, 167 умышленное уничтожение имущества), а тяжкие и особо тяжкие были редкостью. Проверено: все 306 статей достижимы при розыгрыше.

Чтобы добавить статью, допиши объект в массив `ARTICLES`:

```js
{ article: '158', part: 'ч.1', title: 'Кража', sanction: 'лишение свободы до 2 лет', tier: 'medium', weight: 30 }
```

`weight` — чем больше, тем чаще выпадает. `tier` — `minor` / `medium` / `heavy` / `extreme`.

## Запуск

```bash
npm install
copy .env.example .env    # Windows
# cp .env.example .env    # Linux/macOS
```

Впиши в `.env` токен бота из Discord Developer Portal → Bot → Reset Token.

Привилегированные intents:

| Intent | Нужен | Зачем |
|---|---|---|
| Server Members | нет | бот работает только на слэш-командах, участников напрямую не читает |
| Message Content | **да** | без него бот не видит текст сообщений и триггеры не сработают |

**Message Content Intent** включи в Developer Portal → **Bot** → Privileged Gateway Intents. Без него бот запустится, но `/судимость` будет работать, а триггеры в чате — нет. Если увидишь ошибку `Used disallowed intents`, значит тумблер не включён.

BAT-файлы (все тексты в них ASCII — cmd читает файлы в OEM-кодировке и ломает UTF-8):

| Файл | Что делает |
|---|---|
| `start.bat` | Запускает бота. Проверяет Node, `.env`, при первом запуске ставит зависимости |
| `check.bat` | Диагностика: токен → тесты логики → инвайт-ссылка |
| `token.bat` | Вставь токен в `.env` без публикации в чат, сразу проверяет |

```bash
npm start
```

Команды регистрируются глобально при старте, Discord раскатывает их по серверам до часа. Чтобы увидеть сразу на конкретном сервере, нужен инвайт в режиме разработчика: запусти `npm run invite <ID_СЕРВЕРА>`, открой ссылку и добавь бота. ID сервера включается в Discord: Параметры сервера → Виджет ID.

## Данные

Всё хранится в `data/sud.json` (атомарная запись через временный файл). Данные не удаляются при перезапуске. Файл в `.gitignore`.
