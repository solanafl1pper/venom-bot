# venom-bot

Мой дискорд-бот, которого я пилил под свой сервер с пацанами. Надоело держать кучу полумёртвых ботов ради музыки и мелких утилит, поэтому собрал всё в одном месте: нормальный плеер, выкачивание тиктоков, счётчик онлайна в войсе и локальные рофлы.

## Что внутри

- **Музыка без геморроя (`/vplay`)** — играет напрямую с SoundCloud. Ютуб вечно блочит запросы или требует куки, а тут всё стабильно. Жрёт обычные треки, ссылки с телефонов (`on.soundcloud.com`), сеты и плейлисты целиком. Под треком висят простые кнопки (пауза, скип, очередь, стоп) без спама гигантскими карточками.
- **Тикток без водяного знака (`/tiktok`)** — можно кинуть ссылку через команду или просто скинуть в любой текстовый канал, бот сам её подхватит и пришлёт чистое MP4-видео прямо в чат.
- **Счётчик времени в войсе (`/войс`, `/войстоп`)** — трекает, сколько часов каждый сидит в голосовых каналах, и строит топ сервера. Стата пишется в локальную базу и не слетает при перезапуске.
- **Игры** — 2048 прямо в чате на кнопках (`/2048`), плюс поддержка Discord Activities (веб-версии Змейки и 2048 прямо внутри голосового канала).
- **Рофлы и органайзер**:
  - `/судимость` — выдаёт случайные статьи из реального УК РФ (от 1 до 15 штук) со сроком, тяжестью и рекордами.
  - `/рандом` — если лень спорить, кто на ком играет в Доту, бот раскидает 5 человек по позициям и раздаст нормальных героев.
  - `/погода` — погода в любом городе без регистрации и API-ключей.
  - Автоответы на триггеры в чате.

## Команды

| Команда | Описание |
|---|---|
| `/vplay <трек или ссылка>` | Врубить трек или плейлист в войсе |
| `/vskip` | Скипнуть текущий трек |
| `/vqueue` | Посмотреть очередь треков |
| `/vstop` | Заглушить музыку и ливнуть из войса |
| `/tiktok <ссылка>` | Скачать видео без вотермарки |
| `/войс` | Личное время в голосовых каналах |
| `/войстоп` | Таблица лидеров по сидению в войсе |
| `/2048` | Погонять в 2048 кнопками в чате |
| `/судимость` | Розыгрыш статей УК РФ |
| `/рейтинг` | Топ сервера по статьям |
| `/рандом` | Раскидать стак на Доту по ролям |
| `/погода <город>` | Погода за бортом |

## Как поднять у себя

Если хочешь захостить бота у себя на компе или VPS:

1. Ставишь **Node.js 18+**.
2. Клонируешь репозиторий и подтягиваешь зависимости:
   ```bash
   git clone https://github.com/solanafl1pper/venom-bot.git
   cd venom-bot
   npm install
   ```
3. Копируешь файл с настройками:
   ```bash
   copy .env.example .env
   ```
4. В `.env` вставляешь токен своего бота из [Discord Developer Portal](https://discord.com/developers/applications):
   ```env
   DISCORD_TOKEN=твой_секретный_токен
   DISCORD_CLIENT_ID=id_приложения
   ```
5. **Важно:** в Developer Portal во вкладке **Bot** обязательно включи тумблер **Message Content Intent**, иначе бот физически не увидит ссылки на тикток из обычных сообщений и триггеры.
6. Запуск:
   ```bash
   npm start
   ```
   На винде можно просто кликнуть по `start.bat`.
