# venom-bot

Многофункциональный бот для Discord-сервера: музыка из SoundCloud, скачивание видосов из TikTok без водяных знаков, подсчёт времени в войсе, мини-игры прямо в дискорде, рандомайзер Доты и рофляные судимости по статьям УК РФ.

---

## Что умеет бот

### 1. Музыка в голосовых каналах (`/vplay`)
- Стримит треки напрямую с **SoundCloud** в высоком качестве.
- Поддерживает **плейлисты и альбомы**: кидаешь ссылку на сет или пишешь `playlist <запрос>` — бот загрузит всю пачку треков.
- Переваривает любые ссылки: мобильные (`on.soundcloud.com`), ссылки с параметрами (`?si=...`) и обычный текстовый поиск по названию.
- Управление кнопками под сообщением: Пауза, Скип, Очередь, Стоп.
- Чистый минималистичный дизайн без спама огромными эмбедами.

### 2. Загрузка TikTok без водяных знаков (`/tiktok`)
- Отправляешь команду `/tiktok <ссылка>` — бот скачивает видео и присылает чистый MP4 прямо в чат.
- Если просто скинуть ссылку на TikTok в текстовый канал, бот сам её подхватит и отправит готовое видео.

### 3. Подсчёт времени в войсе (`/войс`, `/войстоп`)
- Считает время, проведённое каждым участником в голосовых каналах.
- Показывает личную карточку (сколько дней/часов наговорил) и общий серверный топ болтунов.
- Данные сохраняются локально и не теряются при перезагрузке бота.

### 4. Мини-игры
- **2048 в чате** (`/2048`) — управление кнопками со стрелками прямо под сообщением.
- **Discord Activities** — встроенные веб-игры (2048 и Змейка), в которые можно играть компанией прямо внутри голосового канала.

### 5. Рофлы и утилиты
- `/судимость` — генерирует случайное дело по статьям УК РФ (от 1 до 15 статей) с подсчётом срока, тяжести и рекордами.
- `/рандом` — собирает сбалансированный стак на Доту 2 из участников сервера с раздачей линий и актуальных героев.
- `/погода` — прогноз в любом городе через Open-Meteo без лишней возни с ключами.
- Триггеры и реакции на фразы в чате (РПП, победа, ZOV и т.д.).

## Список команд

| Команда | Описание |
|---|---|
| `/vplay <трек / ссылка / сет>` | Включить трек или плейлист в войсе |
| `/vskip` | Пропустить текущий трек |
| `/vqueue` | Посмотреть очередь треков |
| `/vstop` | Остановить музыку и выйти из войса |
| `/tiktok <ссылка>` | Скачать видео из TikTok без водяного знака |
| `/войс [@юзер]` | Личная статистика времени в голосовых каналах |
| `/войстоп` | Доска почёта: кто дольше всех сидит в войсе |
| `/2048` | Играть в 2048 кнопками в чате |
| `/судимость [@юзер]` | Выдать случайную судимость по статьям УК РФ |
| `/рейтинг` | Топ сервера по тяжести статей и срокам |
| `/рандом` | Собрать стак на Доту из участников с ролью |
| `/погода [город]` | Узнать текущую погоду |
| `/помощь` | Краткая справка по всем командам |

## Как запустить

### 1. Требования
- **Node.js** версии 18 или новее.
- FFmpeg (если в системе нет, бот автоматически использует встроенный `ffmpeg-static`).

### 2. Установка
Клонируй репозиторий и установи зависимости:

```bash
git clone https://github.com/solanafl1pper/venom-bot.git
cd venom-bot
npm install
```

### 3. Настройка (.env)
Скопируй файл конфигурации:
```bash
cp .env.example .env
```
*(на Windows: `copy .env.example .env` или запусти `token.bat`)*

Заполни `.env` данными своего бота из [Discord Developer Portal](https://discord.com/developers/applications):

```env
DISCORD_TOKEN=твой_секретный_токен_бота
DISCORD_CLIENT_ID=id_твоего_приложения
DISCORD_PUBLIC_KEY=публичный_ключ_приложения

# Необязательно:
WEATHER_CITY=Москва
DOTA_ROLE_ID=id_роли_для_доты
STRATZ_TOKEN=токен_stratz_api_для_актуальных_пиков_доты
```

> **Важно:** Во вкладке **Bot** в Developer Portal обязательно включи пункт **Message Content Intent**, иначе бот не сможет читать ссылки на TikTok из чата и отвечать на текстовые триггеры.

### 4. Запуск
```bash
npm start
```
Либо на Windows просто запусти `start.bat`.
